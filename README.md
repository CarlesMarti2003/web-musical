# Web de restaurante
El Musical · Web de restaurante

Proyecto personal de porfolio: una propuesta de web para el restaurante El Musical de Foios.

El objetivo es presentar la carta, los vinos, los menús y la ubicación del restaurante mediante una web sencilla y adaptable a móviles.

Proyecto de aprendizaje no oficial, sin vinculación con el restaurante.

Funcionalidades

Página de inicio con presentación del restaurante.

Carta organizada por categorías, con descripciones y precios.

Carta de vinos dividida en blancos, tintos, rosados, cavas y champagne.

Menús diario, de bocadillos, degustación y de fin de semana.

Selector de pestañas para cambiar entre cartas y menús.

Navegación que permanece visible al desplazarse.

Botón para volver al principio con desplazamiento suave.

Mapa integrado y acceso a indicaciones de Google Maps.

Enlace directo para escribir una reseña en Google.

Diseño adaptable a ordenador y móvil.

La web no permite hacer reservas online. El botón de reserva está preparado para realizar una llamada y está pendiente de incorporar el teléfono definitivo.

Tecnologías

HTML5: estructura y contenido de las páginas.

CSS3: diseño, tipografías y adaptación a diferentes pantallas.

JavaScript: funcionamiento de las pestañas y desplazamiento.

Git y GitHub: historial de versiones y almacenamiento del código.

Cómo ver el proyecto

Clona el repositorio:

git clone https://github.com/CarlesMarti2003/web-musical.git

Abre la carpeta en Visual Studio Code.

Abre el archivo principal index.html en tu navegador.

No requiere instalar dependencias. El mapa y los enlaces de Google necesitan conexión a internet.

Mientras el repositorio sea privado, necesitarás una cuenta con acceso para clonarlo.

Qué estoy aprendiendo

Organizar una web en varias páginas.

Crear diseños con Flexbox y Grid.

Utilizar variables CSS para mantener colores coherentes.

Adaptar la web mediante media queries.

Relacionar elementos HTML con estilos y comportamientos.

Comprender JavaScript mediante funcionalidades concretas.

Guardar avances con commits y subirlos a GitHub.
